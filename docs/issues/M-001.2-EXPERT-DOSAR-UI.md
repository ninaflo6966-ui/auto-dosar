# M-001.2 — Expert Dosar UI

## Status

Implemented.

## Business value

Utilizatorul poate parcurge primul flux configurabil AutoDosar pentru operațiunea „Transcriere auto”, fără logică de business hardcodată în pagină.

## Implementare

- API Next.js pentru lista operațiunilor și detaliul unei operațiuni;
- încărcarea definiției din `OperationRegistry`;
- wizard dinamic, cu întrebări condiționale;
- renderer reutilizabil pentru tipurile de întrebări;
- progres, navigare și rezumat editabil;
- salvarea răspunsurilor în `localStorage` pentru sprintul M-001.3.

## Endpoint-uri

- `GET /api/operations`
- `GET /api/operations/:slug`

## Următorul sprint

M-001.3 — Smart Checklist, alimentat de răspunsurile wizard-ului și definițiile de documente din Operation Registry.
