# M-001.7 — UploadDocumentUseCase

## Status

CLOSED

## Business value

Un document încărcat devine parte a dosarului, iar checklist-ul și scorul se actualizează imediat.

## Implementare

- primește metadatele fișierului și cheia din storage;
- verifică tipul MIME și dimensiunea;
- verifică dacă documentul aparține checklist-ului curent;
- adaugă `CaseDocument` în `CaseFileState`;
- reconstruiește Smart Checklist;
- publică `document.uploaded` și `checklist.updated`;
- returnează proiecția actualizată pentru UI.

Conținutul binar nu este stocat în `adi-core`. API-ul/infrastructura salvează fișierul și transmite use case-ului doar `storageKey` și metadatele.
