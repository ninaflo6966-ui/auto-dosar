# M-001.8 — Smart Upload UI

## Status

COMPLETED

## Business value

Utilizatorul încarcă, previzualizează, înlocuiește și șterge documente direct din Smart Checklist. Scorul dosarului și numărul documentelor lipsă se actualizează fără reîncărcarea paginii.

## Implementare

- sesiune `CaseFileState` creată prin API;
- upload multipart pentru PDF/JPG/PNG, maximum 15 MB;
- stocare locală pentru mediul MVP în `.autodosar/uploads`;
- legare document-checklist prin `operationDocumentId`;
- înlocuire atomică a documentului pentru același element;
- ștergere și recalculare checklist;
- previzualizare securizată prin endpoint dedicat;
- UI responsive în fiecare card al checklist-ului.

## Limitări MVP

Repository-ul dosarelor este în memorie, iar fișierele sunt stocate local. În producție vor fi înlocuite cu PostgreSQL și object storage compatibil S3.
