# M-001.4 — CaseFile Core

## Status

✅ Implementat

## Business value

Dosarul devine obiectul central al produsului. Răspunsurile Expert Dosar, checklist-ul, documentele, scorul și istoricul sunt păstrate într-o singură stare coerentă.

## Implementare

- `CaseFileState` extinde modelul legacy fără breaking changes;
- `CaseFileBuilder` creează un dosar complet inițializat;
- `CaseFileManager` aplică actualizări imuabile și incrementează versiunea;
- checklist-ul și progresul sunt sincronizate;
- documentele pot fi adăugate/eliminate;
- fiecare schimbare intră în timeline;
- `InMemoryCaseFileRepository` oferă persistență de dezvoltare.
