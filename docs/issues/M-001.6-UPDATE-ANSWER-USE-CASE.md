# M-001.6 — UpdateAnswerUseCase

## Status

Completed.

## Business value

Răspunsurile din Expert Dosar sunt salvate în dosarul central, iar checklist-ul este recalculat imediat. UI-ul poate primi într-un singur răspuns starea actualizată, scorul, progresul și documentele necesare.

## Implementare

- `UpdateAnswerUseCase` în stratul application;
- control optimist al versiunii prin `expectedVersion`;
- actualizare imuabilă prin `CaseFileManager`;
- reconstruirea checklist-ului prin `SmartChecklistEngine`;
- persistență prin `ICaseFileRepository`;
- evenimente `case.answers.updated` și `case.checklist.updated`;
- proiecție extinsă pentru UI/API.

## Test

```powershell
npm run test:application
```

## Următorul pas

`UploadDocumentUseCase`, care va adăuga documentul în `CaseFileState`, va recalcula checklist-ul și va întoarce aceeași proiecție actualizată.
